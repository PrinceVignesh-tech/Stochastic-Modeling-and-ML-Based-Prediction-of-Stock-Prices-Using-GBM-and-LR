# **Stochastic Modeling and ML-Based Prediction of Stock Prices Using GBM and Linear Regression**

This project explores the stochastic behaviour of stock prices using **Geometric Brownian Motion (GBM)** and applies **Machine Learning (Linear Regression)** to predict future stock movements. It demonstrates key ideas in stochastic processes, quantitative finance, and predictive analytics.

---

##  **Project Overview**

Stock prices are influenced by randomness and uncertainty.  
This project combines:

- **Stochastic Modeling** (Geometric Brownian Motion)  
- **Machine Learning Regression Techniques**  
- **Exploratory Data Analysis (EDA)**  
- **Simulation of Future Stock Prices**  
- **Predictive Modeling using Linear Regression**

The goal is to understand stock price behaviour and build a simple prediction pipeline suitable for academic research and practical applications.

---

##  **Key Features**

### **1. Geometric Brownian Motion (GBM)**
- Models stock prices using the stochastic differential equation:  
- Simulates future stock prices  
- Captures volatility and expected drift

### **2. Data Analysis & Visualization**
- Log returns  
- Moving averages  
- Trend and volatility analysis  
- Price distribution plots  
- Matplotlib & Seaborn visualizations

### **3. Machine Learning – Linear Regression**
- Extracts features from historical data  
- Train-test split  
- Builds regression-based predictive model  
- Evaluation using:  
  - RMSE  
  - MAE  
  - R² Score
